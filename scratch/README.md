# scratch/

Campaign scratch material moved here from the repository root (E5 hygiene, 2026-11-26)
to keep the umbrella root tidy. Content unchanged; `git log --follow` preserves history.

- `Probe*.lean` — exploratory probe scripts (8).
- `Scratch.lean` (+ `.bak`, `.bak.created_at`) — scratch development file and its backup.
- `prog_dump.txt`, `prog2_dump.txt`, `prog2_err.txt` — program dumps.
- `*_out.txt` — checker/battery output dumps (`py_battery`, `radixdemo`, `rocks`, `steps`).

None of these files are imported by the submission packages (root `Submission/`, `mitm/`,
`hs74-historical/`); they are working material, not part of any filed proof.
